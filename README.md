# Python To-Do List CLI

A beginner-friendly command-line to-do list built with plain Python (no external libraries).

## Features
- Add, view, and remove tasks from a simple menu
- Input validation (bad menu choices, empty tasks, invalid task numbers)
- Tasks saved to `tasks.txt` so they persist between runs

## Requirements
Python 3.6 or newer.

## How to Run
```bash
python todo.py
```
(On some systems use `python3 todo.py`.)

## Example
```
===== TO-DO LIST =====
1. Add Task
2. View Tasks
3. Remove Task
4. Exit
Choose an option (1-4): 1
Enter a new task: Buy groceries
Added: Buy groceries
```
